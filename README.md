# hertg.install_dockge

Ansible Galaxy role to install dockge on Debian.

## Prerequisites

Ensure the [`community.docker.docker_compose_v2`](https://docs.ansible.com/ansible/latest/collections/community/docker/docker_compose_v2_module.html)
module is installed when using this role in a playbook. You might already
have this collection installed if you are using the `ansible` package, 
it is not included in `ansible-core`.

## Installation

```
ansible-galaxy role install hertg.install_dockge
```
