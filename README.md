# hertg.install_dockge

Ansible Galaxy role to install dockge on Debian.

## Prerequisites

This role requires [`community.docker.docker_compose_v2`](https://docs.ansible.com/ansible/latest/collections/community/docker/docker_compose_v2_module.html)
to be installed.

```
ansible-galaxy collection install community.docker
```

## Installation

```
ansible-galaxy role install hertg.install_dockge
```
